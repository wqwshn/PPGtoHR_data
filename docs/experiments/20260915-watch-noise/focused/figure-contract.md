# 图表设计与核验约定

本修订沿用现有 Python/matplotlib 分析，中文、低饱和蓝/陶土色，器件颜色跨图一致。

全部为 quantitative grid，双栏宽183 mm（7.2英寸）、7–8 pt主体文字、白背景。输出300 dpi PNG、可编辑文本SVG与字体嵌入PDF。不是针对某一期刊的正式投稿认证。

1. RMS图：统一0.5–50 Hz后呈现当前四组差异；2个通道，点为3个不重叠10秒窗，短横线为30秒Welch RMS，非独立重复，不做推断检验。
2. PSD图：说明干扰是多峰结构；四组同尺度，标注6.7 Hz间隔参考线，不能按峰频单独定源。
3. 原始波形图：绝对mV、不滤波、不去趋势；固定10–12秒、每图相同电压跨度；均值和±原始SD明示，避免直流差异遮住抖动。SD不是频带RMS。
4. 开机图：绝对1秒均值与60秒滚动斜率；区分下降放缓与长期平稳，不强行拟合热时间常数。
5. RF配对图：每轮连接与复位中间20秒配对；全部三轮公开，包括无改善结果。
6. RF频谱图：等权平均三轮PSD；突出复位后仍保留的20/40 Hz邻域，平均前不跨片段拼接。
7. PPG频谱图：项目腕表四状态对照，2×2同轴范围，三轮等权平均PSD；陶土实线为PPG开、蓝虚线为关，颜色语义在图注明确。突出18–22与38–42 Hz，不能将关闭读取等同于已验证芯片停止内部采样。
8. PPG RMS图：两个通道同纵轴，保留每个状态全部三轮点；短横线为平均功率开方，非独立开关重复实验。范围覆盖全部点与数字，包括关闭PPG后连接Ut1的增加。

主窗口前30秒避开既知项目佩戴阶跃；它不是全记录的无偏总体估计。敏感性检查用前60与末30/60秒，并保留首次项目静置作同批次佩戴前后对照。

QA：原始样本/序号/计数核验，RF完整性与事件时间对齐，带内正弦及奈奎斯特功率合成检查，±1样本相位边界敏感性，PNG文字/遮挡/裁切检查，SVG文本、PDF字体与版面导出检查。所有图仅同一Python后端生成。
