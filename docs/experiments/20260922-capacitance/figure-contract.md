# 图表与证据约定

问题：同一新器件把蓝牙低压电源端电容更换为1 μF后，静置热膜周期噪声是否减弱，开机多久趋于平缓？

术语：HF1=Ut1，HF2=Ut2；新器件始终陶土色，旧器件始终蓝色。本次修订前/后用线型和分面区分，不将修订前误称旧器件。采用原始数据，不使用中值滤波证明硬件改善。

图1：完整记录1秒均值的开机趋势；两通道共同回答基线收敛问题，不画滚动斜率。纵轴绝对mV，横轴MCU上电分钟。
图2：预定末60秒的两路原始波形及其中固定前2秒放大；没有按最低RMS挑选。均值±原始SD，所有统计标注放在标题或图注，避免遮挡。
图3：修订前/后频谱分面，统一坐标；末60秒为主分析，另与历史同上电时刻60秒对照。20/40/33 Hz带指标同时保存，避免只围绕一个消失的峰。

统一100 Hz、Welch 10秒Hann窗、50%重叠、线性去趋势；0.5–50 Hz频带积分开方含Nyquist。整段分30秒窗描绘噪声时变，末30/60/120秒和同上电窗口验证稳定性。不把真实缓变当成高频噪声。新记录只一次，不作总体推断。

Python/matplotlib，宋体+Arial，8英寸宽、主体10 pt、标题11 pt，PNG 300 dpi、SVG可编辑、PDF嵌入字体。每图导出前测量面板对齐，导出后执行文字和碰撞审计，再逐图目视检查。原始数据只读；保留哈希、所有指标和排除规则。
