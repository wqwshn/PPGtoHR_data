二、约定

2.1 协议栈字节序列规定

在本文档所列举的所有功能的指令当中，所有字节都使用 Big-end（大端模式）。所有指
令的字符都使用 ASCII 码进行编码。所有指令均采用‘<’开头，‘>’结尾，结尾没有任何
回车换行符。

所有指令按照发送方向分成了两部分，一部分从 MCU 发送到 BLE 模组，主要负责设置
和查询，使用大写的 ASCII 字符。另一部分从 BLE 模组发送到 MCU，主要负责应答和反馈，
使用小写的 ASCII 字符。

对于从 MCU 发送到 BLE 模组的指令，有设置功能的指令以“<ST”开头，有读取功能

的指令以“<RD”开头。

对于从 BLE 模组发送到 MCU 的指令，BLE 模组用以“<st”开头的指令回复设置指令执

行的结果。BLE 模组用以“<rd”开头的指令回复读取指令的结果。

比如我们设置 BLE 名称为“HongJia”，那么需要发送指令“<ST_NAME=HongJia>”，设
置 成 功 后 会 返 回 “ <st_name=ok> ”。 比 如 读 取 BLE 名 称 为 “ HongJia ”， 那 么 发 送 指 令
“<RD_NAME>”，读取成功会返回“<rd_name=HongJia>”。

2.2 名词解释

我们可以用 MCU 向 BLE 模组发送指令的方式来控制 BLE 模组。同时，BLE 模组收到
从 MCU 发送过来的指令之后会处理并向 MCU 发送反馈信息。从 MCU 向 BLE 模组发送的
指令构成指令流。每一种对相同属性进行读或者写的指令构成一个指令包。从 BLE 模组向
MCU 发送的反馈信息构成应答流。每一种对相同指令包回复的反馈信息构成一个应答包。

关于指令包和应答包的语法，功能和参数，我们在 HJ-131IMH 软件文档的第五章、第六

章和第七章中进行详细讲解。

三、模组工作模式说明

3.1 蓝牙工作模式

HJ-131IMH 内置高性能协议栈，我们针对软件进行了优化，指令和数据我们软件会自动

区分，无需进行模式切换操作，简单易用。

同时我们将 BLE 唤醒引脚与 UART 的 RX 引脚进行复用，最简电路只需要连接电源和串

口的 TX RX 即可，节省外部 MCU 资源。

3.2 数据透传模式和指令模式

对于发送到 HJ-131IMH 的信息，模组内部的固件程序可以识别发送过来的是指令还是数
据。对于发送到模组的指令，模组进入指令模式来处理和应答。对于发送到模组的数据，模
组进入数据透传模式并将数据转发出去。HJ-131IMH 的指令模式与数据透传模式同时工作，
互不影响。友商一般都是利用一个 IO 口或者 AT 指令进行切换，这样操作比较麻烦，我们简
化流程，使模组更加易用。

四、引脚功能说明

4.1 PIN8/P05 蓝牙模组的串口 TX 引脚

数据透传和指令模式下，该引脚作为 BLE 模组的串口 TX 引脚使用，和与之连接的 MCU

控制器的 RX 连接。

4.2 PIN9/P02 蓝牙模组的唤醒与串口 RX 复用引脚

处于低功耗模式下（保持广播或者不广播），该引脚为唤醒中断引脚，高电平有效，该引
脚持续 1ms 以上的高电平即可唤醒 BLE 模组，唤醒后该引脚自动切换为 UART 的 RX 功能，
可以正常接收外部指令或者数据。用户可通过连续发送 3 个字节以上的 0XFF 进行唤醒。

唤醒后，BLE 模组会通过 T2 值进行休眠等待，默认 T2 时间为 1s，那么当串口没有首发
数据通信后，1s 后 BLE 模组会自动休眠，休眠后该引脚 UART 的 RX 功能被禁用，自动切换
为唤醒功能。

唤醒后，该引脚作为 BLE 模组的串口 RX 引脚使用，和与之连接的 MCU 控制器的 TX

连接。

4.3 PIN11/P01 连接状态指示引脚

当 BLE 模组作为从机被手机连接成功后，该引脚输出高电平 1。
当 BLE 模组作为从机被手机断开连接后，该引脚输出低电平 0。

4.4 PIN10/h_RESET 硬件复位引脚(高电平有效)

建议复位引脚与 MCU 的 IO 连接。该引脚高电平有效。复位时，高电平应持续至少 1ms，

然后再拉低即可复位。

对于一些工业环境或者复杂电磁环境，我们建议硬件复位引脚与您的主控 MCU 连接，在

上电的时候一定要进行上电复位操作。

4.5 PIN3/V_HJ 内部 EEPROM 的供电引脚

HJ-131IMH 内置 32Kb 的 eeprom，该引脚为内部 eeprom 的供电引脚，再使用我们的标准

版透传程序的时候，请将该引脚与 PIN2/VCC_HIGH 连接。

用户自行开发固件，请自行处理该引脚。

4.6 PIN4/HJD 内部 EEPROM 的 SDA 引脚

使用我们的标准版透传程序的时候，请将该引脚与 PIN5/P03 连接。
用户自行开发固件，请自行处理该引脚。
