# MAX30101 采集策略评估与优化建议

> 依据当前固件配置、`docs/MAX30101寄存器配置说明.md`、`docs/MAX30101项目配置说明.md` 以及实测文件 `bug/一次多通道采集数据-PPG波形质量低问题/holdbreath1.csv`、`raw_data_20260527_141655.csv`、`0x6F_0x3F.csv`、`0x76_0x5F+增大电流.csv`、`0x6F_0x3F+增大电流.csv` 整理。

## 1. 结论

当前硬件基础上，**可以在保留 Green+Red+IR 三路光谱同步采集的前提下，通过修改 MAX30101 采集策略和 PPG 数据精度链路提升信号质量**。经过五组参数矩阵实验（0x52/0x7F, 0x56/0x7F, 0x56/0x5F, 0x73/0x5F, 0x6F/0x3F），当前确定的最优三路同步基础配置为 **`0x6F/0x3F`（GRI-100-v5）**：400sps / 2x 平均 = 200sps 有效输出，411us 脉宽 / 18-bit 分辨率，三路时序余量 50.7%。该配置三重零差仅 3.8%，FIFO 空读 3.7%，且相比 17-bit 的 0x56/0x5F 在各通道零差率、IR 唯一值数量（927 vs 757）上均有改善。

近期在 `0x6F/0x3F` 基础上完成 LED PA 增大电流对照实验。当前暂定采用 **`0x6F/0x3F + Green=0xE0, Red=0xC0, IR=0xC0`**：它保持 16384nA 量程、18-bit 和三路同步时序不变，同时把 Red/IR DC、AC/DC、唯一值数量和零差率进一步改善。主要副作用是低频漂移相对心率带也同步增大，因此该方案暂定为下一轮静息/屏气/恢复验证配置，而不是最终血氧可靠性结论。

`0x73/0x5F`（800sps / 411us / 3-LED）已确认因时序违规（1233us/1250us = 98.6% 占空比）导致传感器降级到约 50sps 有效输出，不可用于三路同步。

但也要明确边界：本次实验检测位置为**手腕背部**，该位置对红光/红外反射式 SpO2 天然不友好。即使在当前增大电流版本中，Red/IR 的心率带 AC/DC 也只有约 `0.0188% / 0.0436%`，仍显著低于 0.1% 的风险线。波峰波谷不明显不是链路丢包造成的，而是红/红外在该位置的脉动分量太弱、低频漂移相对过强。三路同步采集可以保留 Green 作为腕部心率/灌注参考，也能让 Red/IR 与 Green 在同一采样帧内对齐，但它不能保证腕背达到指夹/指尖血氧的可靠性。

## 2. 当前固件采集配置

当前默认编译配置来自 `Core/Inc/main.h`：

| 项目 | 当前值 |
|------|--------|
| 工作模式 | `CURRENT_WORK_MODE = MODE_HEART_RATE` |
| 数据模式 | `ENABLE_RAW_DATA_PACKET = 1` |
| PPG 通道 | `PPG_DEFAULT_CHANNEL = 2` |
| MCU 采样/发包标称频率 | `PPG_SAMPLE_RATE = 100` |

心率模式实际使用 `PPG_Config_Green_Hardcoded()`，不是单绿光，而是三光路 Multi-LED：

| 寄存器 | 当前值 | 含义 |
|--------|--------|------|
| `MODE_CONFIG (0x09)` | `0x07` | Multi-LED |
| `MULTI_LED_CTRL1 (0x11)` | `0x13` | SLOT1=Green, SLOT2=Red |
| `MULTI_LED_CTRL2 (0x12)` | `0x02` | SLOT3=IR, SLOT4=Disabled |
| `LED3_PA Green (0x0E)` | `0xE0` | 增大电流对照组 |
| `LED1_PA Red (0x0C)` | `0xC0` | 增大电流对照组 |
| `LED2_PA IR (0x0D)` | `0xC0` | 增大电流对照组 |
| `SPO2_CONFIG (0x0A)` | `0x6F` | ADC=16384nA, SR=400sps, PW=411us/18-bit |
| `FIFO_CONFIG (0x08)` | `0x3F` | 2x 平均, rollover, A_FULL=15 |

因此当前已部署三光路策略是：内部 400sps，经 2x 硬件平均后理论输出 200sps，MCU 仍按 100Hz 轮询/发包；固件把同一 Raw 包内读到的 FIFO 样本均值按 Q4 固定小数打包，上位机除以 16.0 保存。这里的”三路同步”指 MAX30101 Multi-LED 在同一 FIFO 样本帧内按 SLOT1->SLOT2->SLOT3 采集 Green/Red/IR，三路时间偏移由 LED 时隙决定，远小于 100Hz 包周期。三路时序约束 `3 x 411us = 1233us < 2500us (1/400sps)`, 余量 50.7%, 确保时序安全。当前暂定 LED PA 使用增大电流版本，用于下一轮验证 `0x6F/0x3F` 加电流后的 DC、AC/DC、SNR、低频漂移和屏气响应方向。

## 3. 实测数据质量评估

实测文件 `holdbreath1.csv` 共 `15115` 行，时间轴 `151.14s`，标称 100Hz。该数据采自旧基线 `0x52/0x7F`，用于说明部署前的问题。2026-05-27 复测文件 `raw_data_20260527_141655.csv` 采自 `0x56/0x7F`，`Seq` 同样全程连续，说明链路丢包不是当前阶梯问题主因。

| 指标 | 结果 |
|------|------|
| `ValidFlag` | 全部为 1 |
| `InterpFlag` | 总和 0 |
| `GapLen` | 总和 0 |
| `MissingBefore` | 总和 0 |
| `Seq` | 全程连续递增 |

### 3.1 PPG 幅值和脉动分量

对三通道做 0.7-3.0Hz 心率带滤波后，得到：

| 通道 | DC 均值 | 占 17-bit 满量程 | 心率带 RMS | 心率带 AC/DC | 主峰 |
|------|---------|------------------|------------|--------------|------|
| Green | 6392 | 4.88% | 23.6 counts | 0.369% | 63.75 BPM |
| Red | 70491 | 53.78% | 16.0 counts | 0.023% | 63.75 BPM |
| IR | 98536 | 75.18% | 53.4 counts | 0.054% | 63.75 BPM |

解释：

- Green 的 DC 很低，但 AC/DC 比 Red/IR 明显高，更像腕部心率通道。
- Red/IR 的 DC 不低，说明光能和 ADC 码值不是完全不够；问题在于脉动 AC 相对 DC 太小。
- Red/IR 的心率峰在频谱中存在，但时域波峰波谷很浅，直接用于 SpO2 的 `AC_red/DC_red` 与 `AC_ir/DC_ir` 会非常敏感。

### 3.2 低频漂移强于心率脉动

低频段 0.08-0.5Hz 与心率带 RMS 比值：

| 通道 | 低频 / 心率带 RMS |
|------|-------------------|
| Green | 1.42 |
| Red | 2.05 |
| IR | 1.77 |

这解释了“波形特征不显著”：红光/红外的脉动成分本来就小，同时慢漂移比心率波更强，时域曲线很容易被基线变化、贴合压力变化、呼吸/血流慢变化淹没。

### 3.3 实际 PPG 新样本率和保存精度不足

虽然 CSV 的 `Seq` 每行递增，100Hz 包完整，但三通道 PPG 数值大约每 2 行才变化一次：

| 指标 | 结果 |
|------|------|
| 任一 PPG 通道变化次数 | 7515 次 |
| 等效 PPG 新样本率 | 约 49.7Hz |
| 三通道完全相同值的连续 run 中位数 | 2 行 |
| 未变化转移比例 | Green 54.7%, Red 55.6%, IR 52.3% |

这说明当前“MAX30101 理论输出 100sps + MCU 100Hz 轮询”的边界太紧。异步轮询下，主循环约一半周期读到 FIFO 空值，固件沿用上次有效均值。它不是本次 Red/IR 弱脉动的唯一原因，但会降低时间分辨率，也会误导上位机以为 PPG 是完整 100Hz。

`0x56/0x7F` 复测仍未解决，`0x73/0x5F` 因时序违规恶化，详见下方 3.4 节参数矩阵对比。

关键发现：

- **8x 平均 (0x7F) 是阶梯化的主因**：无论搭配 800sps 还是 1000sps，输出率贴近 MCU 100Hz 轮询极限，FIFO 总是只有 0~1 个样本，Q4 均值无法生效。
- **0x73/0x5F 因时序违规失败**：3×411us=1233us 与 800sps 周期 1250us 仅差 17us (1.4%)，真实硬件无法满足，传感器降级到约 50sps。
- **0x56/0x5F 和 0x6F/0x3F 均表现优秀**：三重零差均低于 4%，FIFO 空读均约 3.7%，均有含小数行。0x6F/0x3F 在各通道零差率（14.0/11.8/10.2 vs 16.6/14.0/12.7）和 IR 唯一值数量（927 vs 757）上优于 0x56/0x5F，且保持 18-bit 分辨率。
- **Green DC 偏低是腕背位置的固有特征**：17-bit 下约 5% FS，18-bit 下约 2.7% FS。可通过提高 Green LED 电流改善，但需注意不饱和。

### 3.5 近期增大电流对照结果

`0x6F/0x3F + 增大电流` 文件为 `0x6F_0x3F+增大电流.csv`，采样 60.75s，6075 行全部有效，Seq 无丢包。与原 `0x6F/0x3F.csv` 相比：

| 通道 | DC 均值 | 心率带 AC/DC | 心率峰 SNR | 主峰 | 单通道零差 | 唯一值 | 低频/心率带 |
|------|--------:|-------------:|-----------:|-----:|-----------:|-------:|------------:|
| Green 原 0x6F/0x3F | 6967.8 | 0.2542% | 35.07dB | 56.0bpm | 14.0% | 461 | 1.71 |
| Green 增大电流 | 7855.2 | **0.4090%** | 31.93dB | 56.3bpm | **12.7%** | **758** | 3.91 |
| Red 原 0x6F/0x3F | 73045.8 | 0.0135% | 28.17dB | 56.0bpm | 11.8% | 350 | 2.46 |
| Red 增大电流 | 111076.3 | **0.0188%** | **30.99dB** | 56.3bpm | **11.0%** | **802** | 3.71 |
| IR 原 0x6F/0x3F | 108070.5 | 0.0333% | 32.41dB | 56.0bpm | 10.2% | 927 | 2.04 |
| IR 增大电流 | 165724.9 | **0.0436%** | 31.61dB | 56.3bpm | **8.2%** | **1469** | 3.12 |

判断：

- 增大电流后 DC 水平提高：Green 约 +13%，Red/IR 约 +52%/+53%，未见序列丢包或 FIFO 行为恶化。
- 心率带 AC/DC 三通道均提高，说明脉搏调制相对 DC 也增强，不只是整体基线抬高。
- Red 的心率峰 SNR 提升，IR 基本持平，Green 峰值 SNR 下降约 3dB。
- 单通道零差率下降、唯一值数量增加，说明量化台阶和可分辨细节改善。
- 低频/心率带比值同步升高，说明慢漂移也被放大。后续必须在相同佩戴压力、遮光和静息条件下复测，并通过高通/去趋势算法验证是否能保留 AC 改善、抑制低频漂移。

当前阶段的工程取舍：**暂定采用 `0x6F/0x3F + Green=0xE0, Red/IR=0xC0` 继续采集验证**。若后续算法链路包含稳定的去趋势/高通处理，该方案更可能提升 Red/IR 可用性；若后续更重视原始波形低漂移，原 `0x6F/0x3F` 仍是更稳的对照基线。

### 3.6 质量指标计算方式

以下指标用于所有参数组横向比较，应固定口径：

| 指标 | 计算方式 | 解释 |
|------|----------|------|
| 有效行数 | `ValidFlag != 0` 的行数 / CSV 总行数 | 排除上位机插值或无效帧影响 |
| Seq 丢包 | 相邻 `Seq` 按 uint16 环绕计算差值，`delta > 1` 时累计 `delta-1` | 判断 UART/协议链路是否丢 Raw 包 |
| FIFO 空读率 | `_status.csv` 中 `ΔPpgFifoEmptyCounter / ΔSampleCounter` | 判断 MCU 100Hz 轮询是否经常读不到新 PPG 样本 |
| 非空平均样本数 | `ΔPpgFifoSampleTotalCounter / ΔPpgFifoNonemptyCounter` | 判断每次非空读取是否真的读到多个 FIFO 样本 |
| 多样本周期占比 | `ΔPpgFifoMultiSampleCounter / ΔPpgFifoNonemptyCounter` | 判断 Q4 均值是否经常有 2 个及以上样本参与 |
| 三重零差率 | 相邻两行 Green/Red/IR 三元组完全相同的次数 / `(N-1)` | 衡量三通道整体阶梯化和旧值复用程度 |
| 单通道零差率 | 相邻两行同一 PPG 通道值相同的次数 / `(N-1)` | 衡量单通道阶梯化程度，越低越好 |
| 小数行数 | PPG 值存在非整数部分的行数 | Q4 均值是否在 CSV 中保留小数精度 |
| 唯一值数量 | 每通道 `len(set(values))` | 粗略衡量量化细节和动态变化丰富度 |
| DC 均值 | `mean(PPG)` | 反映光强、ADC 码值和饱和余量 |
| 心率带 RMS | 先去均值并线性去趋势，再保留 0.7-3.0Hz 频段，计算 RMS | 近似心搏 AC 分量 |
| 心率带 AC/DC | `心率带 RMS / abs(DC) * 100%` | 反映脉搏调制相对强度，Red/IR 低于 0.1% 时 SpO2 高风险 |
| 低频/心率带 | 0.05-0.5Hz RMS / 0.7-3.0Hz RMS | 判断慢漂移是否盖过心搏，越低越好 |
| 心率峰 SNR | Hanning 窗 FFT，在 0.7-3.0Hz 内找最大峰；峰功率 / 同频带排除峰值 ±0.12Hz 后的中位噪声底，取 `10log10` | 判断心率主峰相对带内噪声是否清晰 |

## 4. 根因判断

当前问题本质是多因素叠加，经实验验证核心根因已明确：

1. **实验位置高风险**：腕背反射式 Red/IR 的脉动分量弱，不是 SpO2 的理想采样位置。
2. **时序约束是三路同步的关键瓶颈**：0x73/0x5F 的失败直接证明了 `3×411us` 在 800sps 下不可行。三路 18-bit 同步采集必须满足 `3×PW < 1/SR` 且有足够余量（建议 >30%）。
3. **8x 硬件平均在 100Hz 轮询下无效**：传感器输出率必须明显高于 MCU 读取率（建议 >1.5x），否则 Q4 均值无法产生小数，阶梯化严重。
4. **固件端整数平均损失小数精度（已修复）**：当前 Q4 固定小数方案已解决此问题。
5. **Red/IR 没有独立闭环调参**：当前电流较高，但没有根据 DC 目标、AC/DC、ALC_OVF、饱和余量做自动或半自动增益控制。
6. **SpO2 分析不应直接依赖当前这组未优化三路数据**：当前 Red/IR AC/DC 太低，直接计算屏气 SpO2 基准实验风险很高；但在三路同步目标下，应先优化 Multi-LED 采集链路，再评估 Red/IR 比值稳定性。

## 5. 推荐采集策略

### 5.1 第一优先级：保留三路 Multi-LED 同步采集

当前目标是优先采用三路光谱同步采集，因此建议继续使用 `MODE_CONFIG=0x07` 的 Multi-LED 模式，并保持：

| Slot | LED | 用途 |
|------|-----|------|
| SLOT1 | Green | 腕部心率、灌注强弱、运动/贴合参考 |
| SLOT2 | Red | SpO2 红光通道 |
| SLOT3 | IR | SpO2 红外通道 |
| SLOT4 | Disabled | 保持关闭 |

这个方向的好处是三路数据来自同一 FIFO 样本帧，便于比较 Green 与 Red/IR 的相位、幅度和运动干扰，也能避免不同模式、不同批次采集导致的贴合状态差异。Red+IR 血氧模式可以作为诊断对照，但不再作为主路线。

### 5.2 第二优先级：三路同步 18-bit 参数配置（已验证）

经过五组实验验证，三路 18-bit (411us) 同步采集的可行配置为 `0x6F/0x3F`。关键约束：`3×411us=1233us` 要求的内部采样周期必须足够大。800sps (1250us) 不可行，400sps (2500us) 余量 50.7% 且实测有效。

最终推荐与对照配置：

| 优先级 | 名称 | 模式 | `SPO2_CONFIG` | `FIFO_CONFIG` | 数据位宽 | 实测效果 |
|--------|------|------|---------------|---------------|----------|----------|
| **暂定推荐** | **GRI-100-v5-hiLED** | G+R+IR | **`0x6F`** | **`0x3F`** | **18-bit + Q4** | **LED=E0/C0/C0, 三重ZD 3.8%, 空读 3.65%, AC/DC和唯一值提升, 低频漂移增大** |
| 基础推荐 | GRI-100-v5 | G+R+IR | `0x6F` | `0x3F` | 18-bit + Q4 | 三重ZD 3.8%, 空读 3.7%, IR唯一值 927, 低频漂移较稳 |
| 备选 | GRI-100-v3 | G+R+IR | `0x56` | `0x5F` | 17-bit + Q4 | 三重ZD 3.9%, 空读 3.7%, 效果接近但仅有17-bit |
| 不推荐 | GRI-100-v6 | G+R+IR | `0x76` | `0x5F` | 17-bit + Q4 | 增大电流后零差率和唯一值仍劣于 0x6F/0x3F |
| 已排除 | GRI-100-v4 | G+R+IR | `0x73` | `0x5F` | 18-bit + Q4 | 时序违规, 有效仅50sps, 三重ZD 50.2% |
| 已排除 | GRI-100-v2 | G+R+IR | `0x56` | `0x7F` | 17-bit | 8x平均导致阶梯, 三重ZD 50.3% |
| 诊断 | RI-100-diag | Red+IR | `0x6F` | `0x1F` | 18-bit | 仅用于诊断 Red/IR 物理上限 |

说明：

- `0x56` = ADC 8192nA、SR 1000sps、PW 215us；三路时隙 `3 x 215us = 645us < 1000us`，时序裕量较好，且仍可沿用当前 17-bit 解包宏。
- **`0x6F/0x3F + 增大电流`（暂定推荐）**：ADC 16384nA、SR 400sps、PW 411us。三路时隙余量 50.7%。18-bit 解包：`MAX30101_PPG_RIGHT_SHIFT=0`、`MAX30101_PPG_VALID_MASK=0x03FFFF`。当前 LED PA 为 Green=0xE0、Red=0xC0、IR=0xC0；Red/IR DC、AC/DC 和唯一值改善，但低频漂移也增大。
- **`0x6F/0x3F`（基础推荐）**：同样满足三路 18-bit 同步，LED PA 较低时低频漂移更稳，可作为加电流方案的长期对照基线。
- `0x56/0x5F`（备选）：ADC 8192nA、SR 1000sps、PW 215us。17-bit 解包：`MAX30101_PPG_RIGHT_SHIFT=1`、`MAX30101_PPG_VALID_MASK=0x01FFFF`。输出率更高 (250sps vs 200sps)，时序更安全 (35.5%)，但仅有 17-bit。
- `0x73/0x5F`（已排除）：时序违规，不可用于三路同步。
- Red+IR 对照组的价值是判断“腕背位置本身是否能提供足够 Red/IR 脉动”，不是替代三路同步方案。

固件落点：上述主路线均应在 `Core/Inc/sample_rate_config.h` 的 `PPG_SAMPLE_RATE == 100` 分支修改 `MAX30101_SPO2_CONFIG_VAL` 和 `MAX30101_FIFO_CONFIG_VAL`；只有 `GRI-100-v4` 还需要同步修改 18-bit 解包宏。

### 5.3 第三优先级：建立三路同步调参指标

每次试验至少记录以下指标，并按窗口统计：

| 指标 | 建议目标 |
|------|----------|
| DC 占满量程 | 30%-80%，优先避免饱和 |
| Green 心率带 AC/DC | 用作腕部贴合/灌注参考，应保持稳定且主峰清晰 |
| Red/IR 心率带 AC/DC | 越高越好；低于 0.1% 时 SpO2 可靠性高风险 |
| 低频/心率带 RMS | 小于 1 更理想；大于 1 表示漂移盖过脉动 |
| FIFO 空读比例 | 应接近 0，不能像当前约 50% 周期复用旧 PPG |
| ALC_OVF | 必须为 0 |

具体公式见 3.6 节。后续报告应同时给出 DC、AC/DC、心率峰 SNR 和低频/心率带，避免只看单一 SNR 或只看时域波形。

调参顺序建议：

1. 固定佩戴压力和遮光条件，优先复测当前暂定的 `GRI-100-v5-hiLED (0x6F/0x3F + Green=0xE0, Red/IR=0xC0)`。
2. 如果重复 PPG 样本率仍高，优先查看 STATUS 中 `PpgFifoEmptyCounter`、`PpgFifoSampleTotalCounter / PpgFifoNonemptyCounter`、单样本/多样本周期占比和 `DEV Hz/RX Hz`，确认是传感器 FIFO 空读、单样本读取占主导，还是佩戴/量化导致。
3. 如果 Red/IR AC/DC 仍低且无饱和，不再优先回到 `0x73/0x5F`；该组合已因 800sps/411us 三路时序余量不足被排除。
4. 如果 DC 低且无 ALC_OVF，逐步提高对应 LED 电流；如果 DC 高但 AC/DC 仍低，不要只继续加电流，优先调整佩戴位置、压力、遮光、ADC 量程和脉宽。
5. Green、Red、IR 分别调，不要默认同一电流。目标是三路都有稳定脉动，Red/IR 可用于比值分析，Green 可作为贴合和运动参考。

### 5.4 第四优先级：改进记录与诊断字段

为后续判断“参数是否真的改善”，当前 STATUS v2 已经增加：

- `PpgFifoSampleTotalCounter`：PPG FIFO 非空周期累计读取样本数。
- `PpgFifoNonemptyCounter`：PPG FIFO 非空读取周期次数。
- `PpgFifoSingleSampleCounter`：只读取 1 个 PPG FIFO 样本的周期数。
- `PpgFifoMultiSampleCounter`：读取 2 个及以上 PPG FIFO 样本并参与均值的周期数。

后续仍建议继续增加：

- 每通道当前寄存器配置快照：`MODE_CONFIG`、`SPO2_CONFIG`、`FIFO_CONFIG`、LED PA。
- ALC_OVF / PPG_RDY / A_FULL 状态统计。
- 实验事件 marker：开始屏气、结束屏气、恢复稳定。

当前 CSV 没有事件 marker，屏气 45s 只能按“中间约 45s”估算，不适合做严肃的 SpO2 延迟和幅度标定。

## 6. 建议实验矩阵

每组至少采集 2-3 分钟，包含静息、屏气、恢复，并同步记录参考指夹血氧仪。

| 组别 | 目的 | 配置 | 结果 |
|------|------|------|------|
| A | 旧基线对照 | `0x52/0x7F` (800sps/8x/17-bit) | 三重ZD 50.3%, 0 小数行 — 基准 |
| B | 三路提速 8x 平均 | `0x56/0x7F` (1000sps/8x/17-bit) | 三重ZD 50.3%, 0 小数行 — 8x 平均无效 |
| C | 三路 4x 平均 17-bit | `0x56/0x5F` (1000sps/4x/17-bit) | **三重ZD 3.9%, 含小数行** — 有效 |
| D | 三路 4x 平均 18-bit | `0x73/0x5F` (800sps/4x/18-bit) | 三重ZD 50.2%, 有效仅50sps — **时序违规, 排除** |
| E | 三路 2x 平均 18-bit | `0x6F/0x3F` (400sps/2x/18-bit) | **三重ZD 3.8%, 含小数行, IR唯一值 927** — **推荐** |
| F | 三路 4x 平均 17-bit + 增大电流 | `0x76/0x5F`, LED=E0/C0/C0 | 零差率和唯一值劣于 0x6F/0x3F，非首选 |
| G | 三路 2x 平均 18-bit + 增大电流 | `0x6F/0x3F`, LED=E0/C0/C0 | **AC/DC、唯一值和零差率改善，低频漂移增大** — **暂定当前方案** |
| H | Red+IR 诊断对照 | `MODE_SPO2`, `0x6F/0x1F` | 待测试 — 判断腕背 Red/IR 物理上限 |
| I | Green 单通道 | `MODE_MULTI`, 仅 Green, 0x77/0x5F | 待测试 — 判断三路是否存在相互干扰 |
| J | 位置对照 | 换指尖或腕掌侧 | 待测试 — 判断硬件/位置上限 |

判定优先级（已完成的 A~G 组结论）：

1. **FIFO 空读率是第一筛选条件**：A/B/D 组均 >50% 空读或等效，直接淘汰。C/E 组空读 3.7%，通过。
2. **三重零差率区分有效/无效配置**：A/B/D 组均约 50%，C 组 3.9%、E 组 3.8%，通过。
3. **18-bit (E 组) vs 17-bit (C 组)**：E 组在各通道零差率、IR 唯一值数量上优于 C 组，且保留 18-bit 分辨率 → **E 组 (0x6F/0x3F) 为推荐配置**。
4. G 组增大电流后在 Red/IR 可分辨细节和 AC/DC 上优于 E 组，但低频漂移更强，因此暂定采用 G 组继续闭环验证。
5. 后续 H/I/J 组用于判断三路同步是否存在相互干扰，以及腕背位置的物理上限。

## 7. 对当前硬件可行性的判断

在不改硬件的前提下，三路 18-bit 同步采集可行：

- **三路 18-bit (411us) 同步的物理边界已明确**：内部采样率不能超过 400sps（周期 2500us，3×411us=1233us，余量 50.7%）。800sps 已被证实不可行。
- **0x6F/0x3F 达到与 0x56/0x5F 同等的链路质量**（三重零差 3.8% vs 3.9%，空读 3.7% vs 3.7%），同时在 IR 通道表现出 18-bit 分辨率优势（唯一值 927 vs 757）。
- **0x6F/0x3F + 增大电流进一步改善 Red/IR 可分辨细节**：Red 唯一值 350->802，IR 唯一值 927->1469，IR 零差率 10.2%->8.2%，但低频/心率带也升高。
- 链路无丢包，后续参数对比可直接看传感器质量指标。

仍需要设置预期：

- 腕背 Red/IR 反射式 SpO2 很可能仍弱于指尖/耳垂，硬件佩戴结构和检测位置可能成为最终瓶颈。
- 如果按推荐配置和佩戴优化后，Red/IR AC/DC 仍长期低于 0.1%，则应考虑更换检测位置、增强遮光/压紧结构，或把当前腕背三路方案定位为心率/趋势检测与多光谱研究数据，而不是可靠血氧绝对值测量。

## 8. 最终推荐

### 8.1 三路同步采集（当前暂定）：`0x6F/0x3F + 增大电流` (GRI-100-v5-hiLED)

| 寄存器 | 地址 | 值 | 说明 |
|--------|------|-----|------|
| MODE_CONFIG | 0x09 | 0x07 | Multi-LED |
| MULTI_LED_CTRL1 | 0x11 | 0x13 | SLOT1=Green, SLOT2=Red |
| MULTI_LED_CTRL2 | 0x12 | 0x02 | SLOT3=IR, SLOT4=Disabled |
| SPO2_CONFIG | 0x0A | **0x6F** | ADC=16384nA, SR=400sps, PW=411us |
| FIFO_CONFIG | 0x08 | **0x3F** | SMP_AVE=2x, Rollover, A_FULL=15 |
| LED3_PA (Green) | 0x0E | 0xE0 | 增大电流对照组 |
| LED1_PA (Red) | 0x0C | 0xC0 | 增大电流对照组 |
| LED2_PA (IR) | 0x0D | 0xC0 | 增大电流对照组 |

固件 18-bit 解包：`MAX30101_PPG_RIGHT_SHIFT=0`, `MAX30101_PPG_VALID_MASK=0x03FFFF`。基础 `0x6F/0x3F` 仍保留为低漂移对照基线；当前暂定采用增大电流版本继续采集闭环。

### 8.2 下一步建议

1. 当前 `0x6F/0x3F + 增大电流` 已确认链路质量达标，建议在 `sample_rate_config.h` 中保持 `0x6F/0x3F`，LED PA 暂定 Green=0xE0、Red/IR=0xC0。
2. 下一步采集静息+屏气+恢复数据，同步记录参考指夹血氧仪，验证 Red/IR 比值在屏气过程中的响应方向。
3. 若需独立测试三路是否存在相互干扰，按以下参数分别测试：
   - **Green 单通道**：`MODE=0x07`, `SLOT1=Green` 仅, `SPO2_CONFIG=0x77` (1000sps/411us/18-bit), `FIFO_CONFIG=0x5F` (4x 平均/250sps)
   - **Red+IR 双通道**：`MODE=0x03` (SpO2), `SPO2_CONFIG=0x77` (1000sps/411us/18-bit), `FIFO_CONFIG=0x5F` (4x 平均/250sps)
4. 后续若低频漂移不可接受，可回退到基础 `0x6F/0x3F` LED 电流，或做更细的 LED PA 扫参；目标是在不饱和的前提下提高 Red/IR AC/DC，并让低频/心率带尽量下降。
